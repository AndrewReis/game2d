## 2D Game: Turn-Based Battle Game
This project is inspired by the classic game Naruto Arena, a game I played a lot during my adolescence. It is a strategic turn-based combat game where players build teams of three characters and face opponents online, using each character's unique abilities.

## Status: In Development

## Technologies:
- Vite.js
- TypeScript
- Phaser 3

## Key Features:
- Turn-Based Combat: Each player controls a team of 3 characters.
- Special Abilities: Each character has unique abilities that require strategy to use at the right moment.
- Basic AI System: Face opponents controlled by AI.
- Online Combat (PvP)
- Ranking System

## MVP Features:
- Turn-Based Combat
- Special Abilities
- Basic AI System
