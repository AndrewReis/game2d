# Game 2d: Turn-Based Battle Game
Este projeto é inspirado pelo clássico jogo Naruto Arena, um jogo que eu joguei muito na adolescência. É um jogo de combate estratégico por turnos onde os jogadores montam equipes de três personagens e enfrentam adversários online, utilizando habilidades únicas de cada personagem.

## Status: Em Desenvolvimento

## Tecnologias:
- Vite.js
- Typescript
- Phaser 3

## Principais Funcionalidades
- Combate por Turnos: Cada jogador controla uma equipe de 3 personagens.
- Habilidades Especiais: Cada personagem possui habilidades únicas que requerem estratégia para serem usadas no momento certo.
- Sistema de IA Básica: Enfrente adversários controlados pela IA.
- Combate online (PvP)
- Sistema de rank
